# Low Power Op Amp Design in Global Foundaries 180nm Process

The aim of this project was to design a low power operational amplifier for tapeout on a MPW run by wafer.space . This readme is a bit of a rush job but will be updated shortly.

##Specs
- Supply voltage, 3v3
- GBW, 1MHz
- Slew rate, >2V/us
- Power consumption, <100uW
- Offset voltage (input ref), 2mV. 

All for nominal load capacitance of 10pF.

A detailed report of the design process will be released following submission of this project
